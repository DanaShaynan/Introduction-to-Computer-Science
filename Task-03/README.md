# 📝 Task 03 — Computing Factors of a Number

## 📌 Assignment

This task was part of the practical coursework for the **Introduction to Computer Science** course. The purpose of the task was to apply loops, conditional statements, and arithmetic operations to solve a mathematical programming problem.

### Question

Develop a solution to compute the **factors of a number**.

## 💡 Approach

The problem was solved by:

1. Reading a number from the keyboard.
2. Starting a loop from 1 up to the given number.
3. Checking whether the number is divisible by the current value.
4. Using the modulus operator `%` to determine whether there is a remainder.
5. If the remainder is zero, the current value is a factor of the number.
6. Displaying all the factors found.
7. Testing the program with different numbers.
