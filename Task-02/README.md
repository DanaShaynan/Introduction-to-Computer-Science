# 📝 Task 02 — Finding the Maximum Number

## 📌 Assignment

This task was part of the practical coursework for the **Introduction to Computer Science** course. The purpose of the task was to practice working with arrays, loops, and conditional statements.

### Question

Write a program that inputs an **array of 10 elements** from the keyboard.

The program should find and print:

* The largest (maximum) number in the array.
* The location of the largest number in the array.

## 💡 Approach

The problem was solved by:

1. Creating an empty list to store the 10 elements.
2. Reading 10 numbers from the keyboard.
3. Storing each input value in the list.
4. Assuming the first element is the largest number initially.
5. Comparing each remaining element with the current maximum.
6. Updating the maximum value and its location whenever a larger number is found.
7. Displaying the largest number and its location.
8. Testing the program using different sets of numbers.

**Python**
