# 📝 Task 01 — Swapping Two Variables

## 📌 Assignment

This task was part of the practical coursework for the **Introduction to Computer Science** course. The purpose of the task was to apply basic programming concepts and develop a solution for swapping the values of two variables.

### Question

Develop a flowchart to swap the values of two variables such as **A = 30** and **B = 50**. After the swap, **A = 50** and **B = 30**.

The solution must not use more than **3 variables**, including A and B.

## 💡 Approach

The problem was solved by:

1. Defining the initial values of variables **A** and **B**.
2. Using a third temporary variable to store the value of **A**.
3. Assigning the value of **B** to **A**.
4. Assigning the stored value to **B**.
5. Displaying the values before and after the swap.
6. Verifying that the values were successfully exchanged.
